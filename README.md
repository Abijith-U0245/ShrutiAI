# 🔊 ShrutiAI
### Offline Privacy-Preserving Hindi Voice Assistant

ShrutiAI is an offline Hindi voice assistant designed for edge devices like Raspberry Pi.  
It performs speech recognition and text-to-speech without internet connectivity, ensuring complete privacy.

---

##  Features

-  Offline Hindi Speech Recognition
-  Privacy-Focused (No Cloud)
-  Lightweight Architecture
-  Command-Based Intent Handling
-  Fully Offline Operation

---

##  Tech Stack

- Python
- Whisper / Vosk (STT)
- Offline TTS Engine
- Raspberry Pi Compatible
